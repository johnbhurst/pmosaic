# Photomosaic System

A system to create photomosaics of a given target image using tiles made up from a library of images.

## Features
- Index library images with grids (2x2, 3x3) and color models (RGB, Oklab).
- Support for JPEG, PNG, HEIC, and CR2 (Canon Raw) formats.
- Create mosaics with optional reuse penalty and easter eggs.
