# Photomosaic

This folder contains an implementation of the photomosaic system by Google Antigravity.

The parent folder and sibling folders contain additional implementations. 
You may consult files in the parent and sibling folders for the purpose of style consistency and other conventions. 
Ignore their implementation details unless specifically instructed to refer to them.

The parent and sibling folders contain their own Python virtual environments. 
Therefore, when running Python scripts in this folder, make sure that you use `uv` with the local virtual environment to ensure the correct libraries are resolved.
